Global context.NumberInWords

Global context

NumberInWords

Available since version 8.0.

Syntax:

NumberInWords(<Number>, <FormatString>, <NumerationItemOptions>)

Parameters:

<Number> (required)

Type: Number.
Number to be represented in words.

<FormatString> (optional)

Type: String.
A format string is a string value that contains the formatting parameters. The Options are separated by semicolon (;). If any option is omitted, the default value is accepted.
Each option is identified by an option name, followed by an equal sign (=) and an option value. You can specify the parameter value in quotes or double quotes. It is necessary when the value of the parameter contains symbols used in syntax of the format string.
  • L - Localization code. Defaults to the localization code set for the operating system. Examples of localization codes: ru_RU - Russian (Russia); en_US - English (USA).
  • SN - Include/exclude numeration item name (Boolean), default is True.
  • FN - Include/exclude numeration item's fractional part name (Boolean), default is True.
  • FS - Display fractional part in words/symbols (Boolean), default is False;
  • AU - Defines generating classic (using "and" conjuction in front of dozens of words and/or units within a triad when writing out in words) or simplified (without the use of conjuction "and") number in words. Makes sense and is analized only for English localization (en, en_XX). Possible parameter values
  • DontUse - generate simplified number in words (used by default);
  • Use - generate classic number in words.

<NumerationItemOptions> (optional)

Type: String.
String defining numbering options. Options are separated by comma (,). Format of the string depends on the localization code.
Numeration item options format:
For Russian, Belarusian and Ukrainian languages (ru_RU, be_BY, uk_UA):
"рубль, рубля, рублей, м, копейка, копейки, копеек, ж, 2", where:
"рубль, рубля, рублей, м" – numeration item:
  • рубль – singular nominative;
  • рубля – singular genitive;
  • рублей – plural genitive;
  • м – masculine gender (ж – feminine gender, с - neutral gender);
"копейка, копейки, копеек, ж" – fractional part, similar to numeration item (optional);
"2" – number of significant fractional digits (optional, default value is 2).
For Ukrainian language (uk_UA):
"гривна, гривны, гривен, м, копейка, копейки, копеек, ж, 2", where:
"гривна, гривны, гривен, м" – numeration item:
  • рубль – singular nominative;
  • рубля – singular genitive;
  • рублей – plural genitive;
  • м – masculine gender (ж – feminine gender, с - neutral gender);
"копейка, копейки, копеек, ж" – fractional part, similar to numeration item (optional);
"2" – number of significant fractional digits (optional, default value is 2).
For Polish language (pl_PL):
złoty, złote, złotych, m, grosz, grosze, groszy, m, 2;
where:
"złoty, złote, złotych, m " - numeration item (m - masculine gender, ż - feminine gender, ń - neutral gender, mo – personal masculine gender);
  • złoty - singular nominative;
  • złote - singular genitive;
  • złotych - plural genitive;
  • m - masculine gender (ż - feminine gender, ń - neutral gender, mo – personal masculine gender);
"grosz, grosze, groszy, m " - fractional part (optional) (similar to integer part);
2 - number of significant fractional digits (optional, default value is 2);
Example:
InWords = NumberInWords(1832, “L=pl_PL;SN=true;FN=true;FS=true”, “złoty, złote, złotych, m, grosz, grosze, groszy, m, 2”);
For English, French, Finnish and Kazakh languages (en_US, fr_CA, fi_FI, kk_KZ):
"dollar, dollars, cent, cents, 2", where:
"dollar, dollars" – numeration item in singular and plural forms;
"cent, cents" – fractional part in singular and plural forms (optional);
"2" – number of significant fractional digits (optional, default value is 2).
For German language (de_DE):
"EURO, EURO, М, Cent, Cent, M, 2", where:
"EURO, EURO, М" – numeration item:
  • EURO, EURO – numeration item in singular and plural forms;
  • М – masculine gender (F – feminine gender, N - neuter gender);
"Cent, Cent, M" – fractional part, similar to numeration item (optional);
"2" – number of significant fractional digits (optional, default value is 2).
For Latvian language (lv_LV):
"lats, lati, latu, V, santīms, santīmi, santīmu, V, 2, J, J", where:
"lats, lati, latu, v" – numeration item:
  • lats – for numbers ending with 1;
  • lati – for numbers ending with 2-9;
  • latu – plural (genitive) used after;
  • numerals 0, 10, 20,..., 90, 100, 200, ..., 1000, ..., 100000;
  • v – masculine gender (s – feminine gender);
"santīms, santīmi, santīmu, V" – fractional part, similar to numeration item (optional);
"2" – number of significant fractional digits (optional, default value is 2).
"J" - number 100 is displayed as "One hundred" for numeration item (N - as "Hundred");
optional, default value is "J";
"J" - number 100 is displayed as "One hundred" for fractional part (N - as "Hundred");
optional, default value is "J";
For Lithuanian language (lt_LT):
"litas, litai, litų, М, centas, centai, centų, М, 2", where:
"litas, litai, litų, М" – numeration item:
  • litas - singular form of integer part;
  • litai - plural form of integer part between 2 and 9;
  • litų - plural form of integer part - others;
  • М - gender of integer part (? – feminine gender);
"centas, centai, centų, М" – fractional part, similar to numeration item (optional);
"2" – number of significant fractional digits (optional, default value is 2).
For Bulgarian language (bg_BG):
"лев, лева, м, стотинка, стотинки, ж, 2", where:
"лев, лева, м" – numeration item:
  • лев - singular form of integer part;
  • лева - plural form of integer part;
  • м - gender of integer part;
"стотинка, стотинки, ж" - fractional part:
  • стотинка - singular form of fractional part;
  • стотинки - plural form of fractional part;
"2" - number of significant fractional digits.
For Romanian language (ro_RO):
"leu, lei, M, ban, bani, W, 2", where:
"leu, lei, M" – numeration item:
  • leu - singular form of integer part;
  • lei - plural form of integer part;
  • M - gender of integer part;
"ban, bani, W" - fractional part:
  • ban - singular form of fractional part;
  • bani - plural form of fractional part;
  • W - gender of fractional part;
"2" - number of significant fractional digits.
For Georgian language (ka_GE):
"ლარი, თეთრი, 2";
  • ლარი - integer part;
  • თეთრი - fractional part;
"2" - number of significant fractional digits.
For Azerbaijanian (az) and Turkmen (tk) languages:
  • "TL" - numeration item;
  • "Kr" - fractional part (optional);
  • 2 - number of significant fractional digits (optional, default value - 2)
For Vietnamese language (vi_VN):
"dong, xu, 2";
  • dong, - integer part;
  • xu, - fractional part;
  • 2 - number of significant fractional digits.
For Turkish language (tr_TR):
"TL,Kr,2,Separate", where:
  • TL - integer part;
  • Kr - fractional part (optional);
  • 2 - number of significant fractional digits (optional, default value is - 2);
  • "Separate" - writing in words separately flag, "Solid" - solid (may not be present, by default - solid).
For hungarian (hu):
"Forint, fillér, 2", where
  • Forint - integer part;
  • fillér - fractional part;
  • "2" - number of significant fractional digits.
Для китайского языка (zh, zh_CN):
"元,角,分,2" , где
  • "元" – юань/предмет исчисления;
  • "角" – цзяо/дробная (одна десятая) часть;
  • "分" – фынь/дробная (одна сотая) часть;
  • 2 – количество разрядов дробной части.

Default value: Empty string.

Returned value:

Type: String.
Number in word form.

Description:

Represents a number in word form, according to the given format string and numeration item options.

Availability:

Thin client, web-client, mobile client, server, thick client, external connection, mobile application (client), mobile application (server), mobile standalone server.

Note:

If the DontUse compatibility mode is set, then method uses locale code, specified for the session (by VL parameter), similar to number and date formatting. by default.

Example:

// Example of the format string for display text in words in english

// with integer and fractional parts and the calculation subject

FormString = "L = en_US; FS = True";
ParametersSubject="dollar, dollars, cent, cents, 2";
NumberSamples = NumberInWords(2341.56, FormString, ParametersSubject);

// Result:

// "Two thousand three hundred fourty one dollar and fifty six cents."
