Global context.GetCommonTemplate

Global context

GetCommonTemplate

Available since version 8.1.

Syntax:

GetCommonTemplate(<CommonTemplate>)

Parameters:

<CommonTemplate> (required)

Type: String, MetadataObject: Template.
The name of the template as it is given in the designer or the common template object of metadata description.

Returned value:

Type: SpreadsheetDocument, TextDocument; another object, which can be a template.

Description:

Receives one of the common configuration templates.

Availability:

Server, thick client, external connection, mobile application (server), mobile standalone server.

Example:

// Receive a common template by name

ConfigStructureTemplate = GetCommonTemplate("ConfigurationStructure");
// Receive a common template by metadata object description

ConfigStructureTemplate = GetCommonTemplate(Metadata.CommonTemplates.ConfigurationStructure);

Available since:

Available since version 8.1.
