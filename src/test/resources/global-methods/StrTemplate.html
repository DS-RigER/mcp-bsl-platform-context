Global context.StrTemplate

Global context

StrTemplate

Available since version 8.3.6 (compatibility with version 8.3.5 and subsequent).

Syntax:

StrTemplate(<Template>, <Value1-Value10>)

Parameters:

<Template> (required)

Type: String.
A strings of placeholders that has the following format: "%1...%N". The placeholder numbering starts from 1. The maximum number is 10.
If a digit follows a placeholder, enclose the placeholder number in parentheses. Example: "%(1)1cv8c.exe"

<Value1-Value10> (optional)

Type: Arbitrary.
Parameters containing arbitrary values possessing string presentations which should be presented in a template. Comma separated.
The amount of values should be equal to N number out of %N. Exceptional situation "Actual parameters are not enough" is generated if the amount of values is not equal to N number out of %N.

Returned value:

Type: String.
Template string with filled parameters.

Description:

Inserts parameters into string by number.

  • If the string contains two % characters in a row (%%), they are regarded as a single percent character, no matter if there is a number immediately after the characters or not.
  • The "Insufficient actual parameters" exception is generated if the parameters are not sufficient to fill in the %N parameter template.
  • The "Too many parameters" exception is generated if there are too many parameters to be inserted into template.

Availability:

Thin client, web-client, mobile client, server, thick client, external connection, mobile application (client), mobile application (server), mobile standalone server.

Note:

If Undefined is used as parameter, it is placed to the result string as an empty string.

Example:

StrTemplate("Data error in line %1 (%2 type required)", 2, "Date")

Available since:

Available since version 8.3.6 (compatibility with version 8.3.5 and subsequent).
