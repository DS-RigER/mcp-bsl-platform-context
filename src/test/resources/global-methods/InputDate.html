Global context.InputDate

Global context

InputDate

Available since version 8.0.

Syntax:

InputDate(<Date>, <Tooltip>, <DatePart>)

Parameters:

<Date> (required)

Type: Date.
Name of the variable available in the module. This variable will be assigned the entered date value. Initial variable value will be used as the initial value in the dialog box.

<Tooltip> (optional)

Type: String.
Text for the date entry dialog box title. Can be used as a Tooltip.
Default value: Empty string.

<DatePart> (optional)

Type: DateFractions.
Date element(s) being entered in the dialog box.
Default value: DateTime.

Returned value:

Type: Boolean.
True - the date is entered; False - the date entry was canceled by user.

Description:

Opens a dialog box to enter the date.
An exception is thrown when the method is called in the web client.

Availability:

Thin client, web-client, mobile client, thick client, mobile application (client).

Note:

If the configuration has the ModalityUseMode property set to DontUse use the ShowInputDate method instead.

Example:

ReminderDate = WorkingDate;
ToolTip = "Enter date and time";
DatePart = DateFractions.DateTime;
If InputDate(ReminderDate, ToolTip, DatePart) Then
    // store  notfication date

EndIf;
