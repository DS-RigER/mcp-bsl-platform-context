# Наименование предопределённого регламентного задания

## 📋 Общая информация

| Параметр | Значение |
|----------|----------|
| **ID проверки** | `mdo-scheduled-job-description` |
| **Severity** | Minor |
| **Тип** | Code style |
| **Стандарт** | № 767 |

## 🎯 Что проверяет

Проверяет, что предопределённым регламентным заданиям не задано наименование в конфигураторе. Вместо наименования достаточно задать синоним.

## ❌ Примеры ошибок

### Пример 1 - Задано наименование

```xml
<ScheduledJob>
  <Name>DataSynchronization</Name>
  <Description>Синхронизация данных</Description>  <!-- ERROR: Description should be empty -->
  <Synonym>Синхронизация данных</Synonym>
  <Predefined>true</Predefined>
</ScheduledJob>
```

## ✅ Правильные решения

### Пример 1 - Без наименования, только синоним

```xml
<ScheduledJob>
  <Name>DataSynchronization</Name>
  <Description></Description>  <!-- Empty or omitted -->
  <Synonym>Синхронизация данных</Synonym>
  <Predefined>true</Predefined>
</ScheduledJob>
```

## 🔧 Как исправить

1. Откройте регламентное задание в Конфигураторе
2. Очистите поле "Наименование"
3. Убедитесь, что заполнен "Синоним"

### Требования к локализации:
- Наименование: пустое
- Синоним: заполнен на языке конфигурации
- Применяется к: предопределённые регламентные задания
