# Привилегированный режим при получении функциональной опции

## 📋 Общая информация

| Параметр | Значение |
|----------|----------|
| **ID проверки** | `functional-option-privileged-get-mode` |
| **Severity** | Major |
| **Тип** | Warning |
| **Стандарт** | № 689 |

## 🎯 Что проверяет

Проверяет, что в функциональной опции установлен флаг "Привилегированный режим при получении". Это необходимо для корректной работы функциональных опций независимо от прав текущего пользователя.

## ❌ Примеры ошибок

### Пример 1 - Флаг не установлен

**XML функциональной опции:**
```xml
<FunctionalOption>
  <Name>UseWarehouse</Name>
  <PrivilegedModeOnGet>false</PrivilegedModeOnGet>  <!-- ERROR -->
</FunctionalOption>
```

## ✅ Правильные решения

### Пример 1 - Флаг установлен

```xml
<FunctionalOption>
  <Name>UseWarehouse</Name>
  <PrivilegedModeOnGet>true</PrivilegedModeOnGet>
</FunctionalOption>
```

## 🔧 Как исправить

1. Откройте функциональную опцию в Конфигураторе
2. На закладке "Основные" установите флаг "Привилегированный режим при получении"

### Исключение
Параметризированные функциональные опции, для которых разработчик специально предусматривает различия в получаемых значениях пользователями с разными правами.

**Пример исключения:** 
Параметризованная ФО `ИспользоватьВалютуПриРасчетеСПерсоналом`, которая параметризуется организацией. Пользователь не увидит поле "валюта" в документе, если у него нет ни одной организации, где применяется валютный учет.
