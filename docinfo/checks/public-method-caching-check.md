# Проверка кэширования программного интерфейса

## 📋 Общая информация

| Параметр | Значение |
|----------|----------|
| **ID проверки** | `public-method-caching` |
| **Severity** | Major |
| **Тип** | Warning |
| **Стандарт** | № 644 |

## 🎯 Что проверяет

Проверяет, что в модулях с повторным использованием возвращаемых значений не создаётся программный интерфейс (секция "ПрограммныйИнтерфейс"). Такие модули должны содержать только служебный программный интерфейс.

## ❌ Примеры ошибок

### Пример - Программный интерфейс в кэшируемом модуле

```bsl
// Common module with ReturnValuesReuse = AtSession

#Region Public  // ← ERROR: Public API in cached module

Procedure GetData() Export
EndProcedure

#EndRegion
```

### На русском:

```bsl
// Общий модуль с повторным использованием

#Область ПрограммныйИнтерфейс  // ← ERROR

Процедура ПолучитьДанные() Экспорт
КонецПроцедуры

#КонецОбласти
```

## ✅ Правильные решения

### Пример - Служебный программный интерфейс

```bsl
// Common module with ReturnValuesReuse = AtSession

#Region Internal

Procedure GetData() Export
EndProcedure

#EndRegion
```

### На русском:

```bsl
// Общий модуль с повторным использованием

#Область СлужебныйПрограммныйИнтерфейс

Процедура ПолучитьДанные() Экспорт
КонецПроцедуры

#КонецОбласти
```

## 🔧 Как исправить

1. Переименуйте область `ПрограммныйИнтерфейс` в `СлужебныйПрограммныйИнтерфейс`
2. Или переименуйте `Public` в `Internal`
3. Для публичного API создайте отдельный некэшируемый модуль-обёртку

### Причина ограничения:
- Модули с кэшированием предназначены для внутреннего использования
- Публичный API должен быть стабильным и не зависеть от деталей реализации
- Кэширование - деталь реализации, а не часть контракта API
